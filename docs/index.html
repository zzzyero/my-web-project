HOW TO HOP

快乐，只需一跳。

  1. 按住屏幕
    按得越久，跳得越远；最长蓄力 1.4 秒。
  2. 松手起跳
    角色自动朝下一个平台跳跃，落空就结束。
  3. 瞄准中心
    落地 +1 分；中心连击依次 +2、+4、+6…
  4. 收集小确幸
    成功落到平台上，即可收集爱心或布丁，额外 +3 分。

两位角色操作规则相同，最高分分别保存在当前浏览器。首跳约蓄力 0.7 秒，之后靠手感挑战！
